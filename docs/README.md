# Influence 제품 문서

이 디렉터리는 스토리로그의 제품·디자인·개발 결정을 내릴 때 사용하는 기준 문서다.

## 서비스 한 줄 정의

**스토리로그는 한국어 AI·테크 예비 크리에이터가 텍스트·음성·사진·영상을 원하는 조합으로 남기고 선택한 일정과 AI 질문으로 맥락을 보완하면, 나다운 Instagram Reel·Carousel 게시물·Story 제작 패키지로 바꿔 주는 AI 워크플로우 서비스다.**

MVP는 최종 영상·이미지를 렌더링하거나 Instagram 계정을 대신 운영하지 않는다. Storyboard와 대사·카피·자막·CTA·제작 지시안을 제공해 사용자가 직접 완성·게시하도록 돕는다.

## MVP 제품 파이프라인

```text
공용 초대 코드
→ Google 로그인
→ 텍스트·음성·사진·영상 자유 조합 기록
→ 선택적 Google Calendar 연결·일정 선택
→ 비동기 AI 질문·음성 녹음 또는 텍스트 답변
→ 대화 로그·브랜드 설정
→ StoryCard 최대 3개
→ 사용자 선택·수정·승인
→ 개인 RAG + 권리 확인 포맷 패턴 RAG
→ 내부 Content Brief
→ Reel·Carousel·Story 제작 패키지와 목업
→ 사실성·민감정보·유사성 검사
→ 포맷별 수정·승인·경고 확인
→ 화면 복사·ZIP 내보내기
→ 사용자가 직접 완성·Instagram 게시
→ URL·24시간·72시간 성과 입력
```

핵심 산출물은 다음처럼 구분한다.

| 산출물 | 답하는 질문 | MVP 노출 |
|---|---|---|
| `StoryCard` | 어떤 경험을 콘텐츠로 만들 것인가? | 최대 3개 후보, 필수 검토·승인 |
| `Content Brief` | 누구에게, 왜, 무엇을 전달할 것인가? | 시스템 내부 산출물 |
| `ContentPackage` | 포맷별로 무엇을 어떻게 제작할 것인가? | Reel·Carousel·Story 제작안, 필수 검토·승인 |
| `QualityReview` | 어떤 문장을 수정·제외·확인해야 하는가? | 점수 없이 근거가 연결된 행동형 경고 |

## 확정 MVP 범위

- 사용자: 한국어 AI·테크 예비 크리에이터
- 운영: 4주, 20명 초대 베타
- 접근: 초대 코드 통과 후 Google 로그인
- Calendar: 별도 읽기 권한, 사용자가 선택한 일정만 저장
- 입력: 텍스트 5천 자, 음성 합계 3분, 사진 5장·각 10MB, 영상 합계 3분·200MB를 한 기록에서 자유롭게 조합
- AI 질문: 실시간 통화가 아닌 비동기 질문에 녹음 또는 텍스트로 답변
- 출력: Reel 대표, Reel·Carousel 게시물·Story 제작 패키지 3종과 목업
- 전달: 승인·경고 확인된 패키지의 화면 복사와 선택 ZIP
- 게시: 사용자가 최종 미디어를 완성해 직접 게시하고 URL 등록
- 성과: 24시간·72시간 지표 수동 입력
- AI/RAG: FastAPI → AWS RDS PostgreSQL/pgvector → OpenAI Responses API
- 모델: GPT Transcribe, `text-embedding-3-small`, GPT-5.6 Terra·Sol 역할 분리
- 보존: 원본 미디어 30일, 텍스트·파생 데이터·개인 RAG는 마지막 활동 후 180일

MVP에는 최종 미디어 렌더링, Instagram OAuth/API 게시, 예약·자동 게시, 자동 성과 수집, 실시간 음성 통화, LinkedIn·X·YouTube, Trial Reel 자동화, 결제가 포함되지 않는다.

## AI와 RAG 원칙

1. 개인 RAG와 Reel·Carousel·Story 포맷 패턴 RAG를 논리적으로 분리한다.
2. 개인 RAG는 Google 사용자별 브랜드 프로필·승인본·수정·거절 이력만 검색한다.
3. 패턴 RAG에는 원본 게시물이 아니라 훅·구조·목적·성과·권리 근거 같은 파생 정보만 저장한다.
4. Instagram 레퍼런스 2만 건은 아직 확보되지 않았으며, MVP는 팀 작성 또는 권리 확인 시드 패턴만 사용한다.
5. HikerAPI 운영 수집은 상업적 분석·저장·파생 패턴 활용 권리가 서면으로 확인될 때까지 비활성화한다.
6. OpenAI에는 직접 식별정보를 제거한 최소 문맥만 `store=false`로 보낸다.
7. 내부 검사는 사실성·민감정보·원본 유사성을 확인하되 숫자 품질 점수는 노출하지 않는다.
8. StoryCard 승인, 포맷별 승인, 품질 경고 해결·확인이 콘텐츠 책임 경계다.

## 문서 지도

- [제품 기획 기준](./product-spec.md): 확정 사용자 흐름, 입력·출력, AI/RAG, 품질 경고, 데이터 계약, 보존·삭제, 검증 시나리오와 베타 성공 기준
- [인플루언서 카탈로그](./influencer-catalog.md): 프로필 데이터 정규화, 검색 API, 출처·신선도 정책과 패턴 RAG 승격 조건

첨부 서비스 기획서와 PWD·IA를 제품 범위의 우선 기준으로 사용한다. AI 스택은 기술 참고자료, Granola 무드보드는 디자인 참고자료이며 기능 범위를 확장하지 않는다.

## 문서와 구현 상태

2026-08-16 기준 로컬 MVP에는 다음 세로 흐름이 구현되어 있다.

- 초대 코드와 Google OAuth, 키가 없는 로컬 환경의 개발 로그인
- 선택적 Calendar 연결과 선택 일정 저장
- 텍스트·음성·사진·영상 복합 입력, FFmpeg 기반 영상 음성 추출
- 비동기 질문의 텍스트·음성 답변과 브랜드 프로필
- StoryCard 최대 3개와 원문 근거, 선택·수정·승인·거절
- PostgreSQL/pgvector 개인 RAG와 권리 확인 시드 패턴 RAG
- OpenAI Responses 구조화 출력과 `store=false`, 키가 없을 때 체험 AI
- Reel·Carousel·Story 제작 패키지와 제작 전 목업
- 사실성·개인정보·유사성 행동형 경고와 승인 전 확인
- 포맷별 복사·승인, 원본을 포함한 선택 ZIP
- Instagram 직접 게시 URL과 24·72시간 성과 입력
- 기록 삭제, 원본 30일·작업 공간 180일 보존 기한 정리 작업

실제 Google 로그인·Calendar와 OpenAI 호출에는 각 공급자 키가 필요하다. 키가 없는 기본 로컬 실행은 외부 전송 없이 동일한 화면과 데이터 계약을 확인하는 체험 모드로 동작한다. Instagram API 게시, 최종 미디어 렌더링, HikerAPI 수집, 결제는 구현하지 않았다.
